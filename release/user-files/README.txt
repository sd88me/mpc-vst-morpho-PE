Morpho-PE: put your own files here, then restart MPC (this folder is read at start-up).

  .syx program / bank dumps          from a Poly Evolver or Evolver: each bank becomes a bank on the BANKS tab
  two .bin or .rom files             a Prophet VS's high-byte and low-byte program ROM chips (27256, 32 KB each, either order):
                                     the 95 factory waves, exact
  one single-cycle .wav              the VS waves as a recording (cycles marked by cue points): the same waves, approximately
  .syx Waveshape Data dumps          from a Poly Evolver / Evolver: each dumped wave replaces its own slot
  .syx Prophet VS wave dump          the VS's 32 RAM waves: they become waves 97-128

Nothing from the instrument is shipped with the plugin. The Program tab's status line shows how many banks and waves were found.
